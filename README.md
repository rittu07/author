# Great Lives, Retold

An immersive, first-person interactive biographical storytelling experience celebrating legendary authors and visionary minds.

## 📖 Overview

**Great Lives, Retold** invites readers to step through the pages of history and listen to the personal journeys of influential figures—told in their own voices, one scene at a time. Each life story is presented through a carefully dramatized episodic narrative paired with atmospheric visuals, bespoke typography, and speech synthesis.

## ✒️ Featured Authors & Figures

- **William Shakespeare** (1564–1616) — *The Bard of Avon*
- **Charles Dickens** (1812–1870) — *A fireside tale of Victorian London*
- **Leo Tolstoy** (1828–1910) — *The conscience of Yasnaya Polyana*
- **Lewis Carroll** (1832–1898) — *Down the rabbit hole in Oxford*
- **Mark Twain** (1835–1910) — *Steamboats and stories on the Mississippi*
- **Arthur Conan Doyle** (1859–1930) — *Fog and deduction at 221B Baker Street*
- **Robert Frost** (1874–1963) — *The road not taken in New England*
- **A. P. J. Abdul Kalam** (1931–2015) — *Dream, learn, and fly from Rameswaram*

## ✨ Features

- **Episodic First-Person Narratives**: Each figure narrates their life story across pivotal chapters—from early beginnings and creative breakthroughs to their lasting legacies.
- **Atmospheric Visuals**: Curated portraits, dynamic radial ambient glow, and color palettes tailored to each author's era.
- **Period-Specific Typography**: Custom Google Fonts pairings including *IM Fell English*, *Playfair Display*, *EB Garamond*, *Old Standard TT*, *Libre Baskerville*, *PT Serif*, and *Lora*.
- **Integrated Voice Synthesis**: Powered by the Web Speech API with tailored language accents, pitch, and cadence controls with audio toggle.
- **Scene Navigation**: Interactive playback controls for pausing, resuming, stepping back, or advancing through the story arc.
- **Zero-Dependency & Self-Contained**: Pure HTML, CSS, and vanilla JavaScript with embedded artwork. Ready to run anywhere without build tools or servers.

## 🚀 Getting Started

Simply open `index.html` in any modern browser:

```bash
# Clone the repository
git clone https://github.com/rittu07/author.git

# Navigate into the project directory
cd author

# Open in your browser (Windows)
start index.html
```

Or serve locally with any static web server:

```bash
npx serve .
# or
python -m http.server 8000
```

## 🌐 GitHub Pages Deployment

To host this project live for free using GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/rittu07/author`
2. Click **Settings** > **Pages** (under the "Code and automation" section).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Your site will be live at: `https://rittu07.github.io/author/`
